拒绝付费套路与隐私隐患：我做了一款全能纯本地桌面端 PDF 百宝箱（完全开源）

> 项目地址：https://github.com/baobanxian/PDF-tools

> 最新版本：v1.0.0 绿色免安装版

> 技术栈：Python 3.10+ / PyMuPDF (fitz) / LibreOffice Headless / CustomTkinter / PyInstaller

一、 为什么做这个工具？—— 源于真实办公痛点

作为一个日常需要频繁处理各种材料的打工人/学生党，谁还没被各类 PDF 工具折磨过几次？

1. 让人抓狂的大小限制：报销系统、政务申报网站、考研/招聘上传入口，动辄规定“附件不得超过 5MB / 10MB”。随手扫描的一份几十页合同就有 40MB，直接被无情拦截。

2. 防不胜防的付费陷阱：在搜索引擎里找“PDF 压缩”、“Word 转 PDF”，搜索结果充斥着各种商业在线转换工具。兴冲冲上传完，处理到最后一秒弹出一个弹窗：“开通 39 元月卡解锁下载”，或者“非会员仅支持前 3 页”。

3. 触目惊心的隐私隐患：身份证复印件、财务报表、商务合同、带有敏感批注的论文……把这些文件上传到不知名服务器的云端，极易存在核心数据泄露的风险。

4. 糟糕的合成体验：把几十张按 1.png, 2.png... 10.png 命名的图片合成为 PDF，绝大多数工具按纯字典序排列，第 2 页永远是 10，排版当场报废。

既然市面上缺少一款完全免费、纯本地离线、不耍流氓、开箱即用的综合 PDF 工具，作为一名开发者，我决定自己动手开发一款！

今天，这款完全开源、无需安装任何复杂环境的 【PDF 百宝箱 (PDF-Toolbox)】 正式发布了 v1.0.0 版本。

二、 核心架构设计：如何做到“纯本地”与“全能”？

为了兼顾速度、格式宽度和用户体验，在技术选型上做了清晰的分工：

               ┌───────────────────────────────┐
               │    CustomTkinter 现代卡片 UI   │
               └───────────────┬───────────────┘
                               │ (后台异步多线程调度)
               ┌───────────────┴───────────────┐
               │          调度与业务逻辑层        │
               └───────┬───────────────┬───────┘
                       │               │
        【PDF/图片/表格/Markdown】   【Word/PPT/Excel】
                       ▼               ▼
               ┌───────────────┐ ┌───────────────┐
               │    PyMuPDF    │ │  LibreOffice  │
               │ (毫秒级响应/C++)│ │ (内置无头转换) │
               └───────────────┘ └───────────────┘

1. PyMuPDF (fitz) 负责绝对的性能输出：

底层基于高性能 C++ 渲染引擎 MuPDF。PDF 转图片、流压缩、表格提取、高亮读取均在毫秒级完成，纯 Python 绑定，零外部软件依赖。

2. 嵌入式 LibreOffice 充当格式转码后盾：

微软 Office（Word、PPT、Excel）的排版规范极度庞大且闭源。我将便携版 LibreOffice 进行了定向物理“大瘦身”，剔除冗余多媒体和文档库，将其封装为独立的后台无头服务，完美弥补了开源世界解析 Office 的短板。

3. CustomTkinter 打造高颜值前端：

摒弃了传统 Tkinter 丑陋陈旧的 90 年代风格，采用类似 Win11 Fluent 的浅色磨砂质感卡片布局，并引入后台线程调度，保证大文件处理时界面绝不卡顿假死。

三、 九大核心功能：打磨到极致的细节

在实现功能的过程中，拒绝粗暴的“调库了事”，而是针对真实办公痛点做了深度优化：

1. PDF 转高清图（告别模糊）

拒绝市面工具直接截屏导致的模糊画质。底层依据精准缩放矩阵转换，提供三种直观档位：

* 150 DPI（极速分享）：体积小巧，极度适合微信发送、邮件流转；

* 200 DPI（标准清晰）：电脑端查看的最佳平衡点；

* 300 DPI（印刷级超清）：高精细矢量印刷标准，放大看边缘依旧锐利。

2. 多图合并转 PDF（数字自然排序算法）

彻底消灭 1.png, 10.png, 2.png 导致的排序灾难！利用正则切分提取数字块，强制执行人类直觉的自然排序。覆盖 PNG、JPG、WEBP、TIFF、BMP 等所有主流格式。

3. PDF 智能瘦身（救命的三档压缩）

* 低档：无损清理 PDF 底层未引用的垃圾对象（Garbage Collection）与流压缩；

* 中档：深度清理并合并重复流对象；

* 高档：遍历提取内嵌的高清扫描图片，自动降采样重编码。实测可将 50MB+ 的臃肿扫描件直接压缩至 5MB 以内。

4. 财报 / 发票表格提取为 Excel

财务人员的福音！利用几何线框算法自动分析 PDF 页面中的二维表格结构，并一键无损导出为可编辑的 .xlsx 或 .csv。

5. Office 一键直出高保真 PDF

输入任意 .docx、.pptx、.xlsx，后台通过隔离的用户目录并发转码，不弹窗、不骚扰，排版与原版高度一致。

6. Markdown 双向互通与高亮读书笔记提取

* 支持 .md 文档一键排版导出为 PDF；

* 读书神器：扫描 PDF 中用 iPad、阅读器画的黄色高亮注释，只提取被划线的关键原文，整理成结构化的 Markdown 读书摘要！

7. 真正的物理级脱敏与防伪水印

* 添加水印：支持自定义文字、倾斜度、半透明度与图层位置；

* 真·脱敏删除：普通软件画个黑块盖住文字，鼠标一选中就能复制出原文。本项目采用 Redaction 物理擦除，直接从数据流层抹去敏感信息，绝无反向泄密风险。

四、 踩坑记录：打包过程中惊心动魄的“套娃翻车”

在将整个工具使用 PyInstaller 编译为 Windows 绿色独立免安装包时，经历了一次搞笑又深刻的教训：

翻车现场：打包出来的产物居然高达 1.33 GB！

按照最初设想，核心代码 50MB + 瘦身后的 LibreOffice 引擎 580MB，整包应该在 640MB 左右。

然而打包脚本一跑完，右键属性一看：1.33 GB！包含两万多个文件！ 😱

排查过程：

仔细排查生成的 _internal 目录才发现，自动化打包脚本在调用 PyInstaller 时加了 --add-data "engine;engine"，把 580MB 的引擎塞进了 .exe 的内部运行库里；接着脚本在外面又通过 shutil.copytree 把引擎复制了一遍！

同一个引擎被完完整整装了两整份！

终极解决方案：

彻底解耦外部依赖与 Python 核心，PyInstaller 仅负责编译纯净的 Python 前端逻辑（体积仅 40MB），外部通过相对路径单例挂载 engine/。整包打成 .zip 压缩包后，实际下载体积仅 150MB 出头，解压双击秒开！

五、 快速上手使用

本项目承诺永久开源、完全免费、零商业广告、零后台上传。

Windows 用户（开箱即用）：

1. 前往 GitHub 的 Releases 页面；

2. 下载 PDF百宝箱_v1.0.zip，解压到任意文件夹；

3. 双击里面的 PDF百宝箱.exe 即可打开使用（无需安装 Python，无需安装任何运行库）。

开发者 / 源码运行（支持 Windows & macOS）：

# 1. 克隆仓库
git clone [你的仓库链接]
cd pdftools

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行主程序
python run_gui.py

六、 下一阶段迭代计划（Roadmap）

目前的 v1.0.0 版本已经实现了所有预期的核心功能，但在用户体验和重度办公场景下，仍有很大提升空间。接下来的版本将重点攻关以下三个方向：

1. 界面美学与交互质感升级（UI 2.0）：

- 深度优化高分屏与视网膜屏幕的渲染适配；

- 进一步打磨卡片阴影、圆角微动效与半透明液态玻璃质感，让界面更加现代精致。

2. 全流程批量文件处理能力：

- 引入文件批量列表与排队任务机制，支持一次性拖入数十个 PDF 或 Word/PPT 文档；

- 支持一键“批量压缩”、“批量转图片”或“批量加水印”，彻底释放重复劳动力。

3. 更人性的导出交互体验：

- 优化输出路径管理，支持“记住上次选择的导出目录”与自定义命名规则模板；

- 任务完成后增加系统原生提示，并提供 “一键打开目标文件夹 / 定位文件” 的快捷操作，无需用户再手动翻找目录。
